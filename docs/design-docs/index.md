# Design Docs Index

This folder captures the product and interface direction for Bedroom Layout Designer.

## Documents

- [Core Beliefs](./core-beliefs.md): Core mission, product beliefs, and current visual style baseline.

## Scope

These docs are intended to keep design decisions consistent with the current app:

- Browser-based bedroom planning with no backend dependency.
- Fast iteration on room layout, measurements, and export.
- Clear, low-friction interactions across desktop and mobile.
